## 1. Opis działania aplikakcji

Aplikacja służy do pokazania różnych sposobów sortowania.

Aplikacja konsolowa została napisana w języku Python

Aplikacja desktopowa została napisana w języku Python z użyciem biblioteki Tkinter

Aplikacja webowa została napisana w React + Vite + JS

Aplikacja mobilna została napisana w kotlin w Android Studio

## 2. Algorytmy sortowania

1. Sortowanie bąbelkowe (BubbleSort)
   
2. Sortowanie poprzez wstawianie (InsertionSort)
   
3. Sortowanie poprzez wybieranie (SelectionSort)
   
4. Sortowanie szybkie (QuickSort)
   
5. Sortowanie heap (HeapSort)

## 3. Uruchamianie aplikacji

## 3.1 Aplikacja konsolowa

Aby uruchomić aplikację konsolową należy wejść w edytor np VSC, wejść do folderu aplikacja_konsolowa, wybrać plik console_sorting.py oraz nakliknąć F5 lub Run.

## 3.2 Aplikacja desktopowa

Aby uruchomić aplikację konsolową należy wejść w edytor np VSC, wejść do folderu aplikacja_konsolowa, wybrać plik console_sorting.py oraz nakliknąć F5 lub Run.

## 3.3 Aplikacja webowa

Aby uruchomić aplikację konsolową należy wejść w katalog aplikacja_webowa

```bash
cd aplikacja_webowa
```

następnie wpisać:

```bash
npm run dev
```

na końcu kliknąć w link trzymając w tym samym czasie ctrl do localhost lub skopiować link i wkleić do przeglądarki

## 3.4 Aplikacja mobilna

Aby uruchomić aplikację konsolową należy wejść w Android Studio, otworzyć emulator, odnaleść plik MainActivity.kt oraz po właczeniu emulatora właczyć aplikacje.
